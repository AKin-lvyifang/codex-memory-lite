# Codex Memory Lite v2.0.0 - 自动项目记忆 / Automatic Project Memory

![Codex Memory Lite v2.0.0](https://raw.githubusercontent.com/AKin-lvyifang/codex-memory-lite/v2.0.0/docs/images/codex-memory-lite-v2.0.0.png)

## 中文

### 新功能

- 从 V1 的 4 个手动 Skill，升级为单一 V2 Skill 和自动 Hook。
- 项目第一次收到 Prompt 时自动初始化或迁移 `.codex-memory/`，不再占用项目 `AGENTS.md`。
- 只在文件变化、明确长期信号、压缩检查点或积压阈值出现时启动 Curator；普通短对话保持安静。
- 通过只读判断、来源覆盖校验、事务和原子写入，避免模型直接覆盖长期记忆。
- 安装、更新和卸载都会保留其他 Hook、MCP、Skill、配置和所有项目记忆。

### 使用方法

```bash
npx --yes --package=github:AKin-lvyifang/codex-memory-lite#v2.0.0 codex-memory-lite install
```

安装后新建 task 或重启 ChatGPT / Codex，再执行：

```bash
npx --yes --package=github:AKin-lvyifang/codex-memory-lite#v2.0.0 codex-memory-lite doctor
```

从 V1 升级时，先验证一个项目，再按迁移说明退出旧 Skill 和 `AGENTS.md` 记忆路由；安装器不会擅自删除它们。

### 下载

Release 资产提供 TGZ、ZIP 和 `SHA256SUMS`。完整说明见 [中文 README](https://github.com/AKin-lvyifang/codex-memory-lite/blob/v2.0.0/README.zh-CN.md)。

## English

### What's New

- Replace the manual four-Skill V1 workflow with one V2 Skill and automatic lifecycle Hooks.
- Initialize or migrate `.codex-memory/` on the first project prompt without using project `AGENTS.md` as the memory engine.
- Run Curator only after workspace changes, explicit durable signals, compaction checkpoints, or pending thresholds; ordinary short turns stay silent.
- Separate read-only judgment from validated transactional writes so the model cannot overwrite durable memory directly.
- Preserve unrelated Hooks, MCP servers, Skills, configuration, and every project memory directory during install, update, and uninstall.

### How To Use

```bash
npx --yes --package=github:AKin-lvyifang/codex-memory-lite#v2.0.0 codex-memory-lite install
```

Start a new task or restart ChatGPT/Codex, then run:

```bash
npx --yes --package=github:AKin-lvyifang/codex-memory-lite#v2.0.0 codex-memory-lite doctor
```

For V1 upgrades, validate one project first, then retire the old Skills and `AGENTS.md` memory routing deliberately. The installer does not remove them silently.
